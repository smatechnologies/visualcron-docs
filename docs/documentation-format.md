## Documentation Format

This page lists the format conventions used in this documentation.

- [visualcron.com](https://www.visualcron.com): a link to a web page or to another page of this documentation
- _Italics_: a field, option or check box label, exactly as the Client shows it
- ***Bold italics***: a ribbon tab, menu, button or window tab name, for example the ***Triggers*** tab
- **Bold**: a defined term, or a heading inside a paragraph
- "value": an option value, or a value to select or enter
- `_Label_: description`: how the fields of a window or tab are listed
- `code`: a command, path, file name or sample, and placeholders such as `<name>`
- `->`: a path through the ribbon or a menu, for example ***Server*** -> ***Settings***

Notes, information, tips and warnings are shown as boxes. A warning marks a setting or behavior that can cause data loss, a Task that reports success without doing its work, or credentials or certificates that are not checked.
