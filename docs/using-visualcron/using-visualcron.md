## Overview

This section explains how VisualCron is built and how you work with it day to day. Read it first if you are new to VisualCron. If you have not installed VisualCron yet, see [Download, Install, Upgrade and Uninstall](../get-visualcron/download-install-upgrade-uninstall).

VisualCron has three parts:

- The VisualCron Server, a Windows service that runs your Jobs
- The VisualCron Client, the Windows application you use to create and manage Jobs, Tasks and settings
- The VisualCron Tray Client, a small application in the Windows notification area that starts the Client, controls the Server and runs Tasks that need the logged-on user's desktop

You can also manage a Server from a browser with the Web Client, after you install it in IIS or IIS Express. See [Installation of Web Client](installation-of-web-client). Unless stated otherwise, the steps in this help refer to the Client.

The Server status is "On" the first time the Server starts, so active Jobs run as soon as their Triggers fire. See [Main - Server On/Off](../client-user-interface/server/server-on-off).
