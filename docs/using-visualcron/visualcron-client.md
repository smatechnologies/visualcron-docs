## VisualCron Client

This page explains what the VisualCron Client is and how it relates to the Server.

The VisualCron Client is the Windows application you use to configure VisualCron and to manage the Jobs and Tasks that the Server runs. It is separate from the Server, so you can close it without affecting running Jobs.

Several Clients can be connected to the same Server at the same time. Typically, the Client and the [Tray Client](visualcron-tray-client) on the same computer are both connected. To see which Clients are connected to the current Server, click _Server_ -> _Main settings_ -> _Client connections_. You need the _Read_ permission for _Client connections_ in the permissions of your user group; see [Main - User Permissions](../client-user-interface/server/main-user-permissions) and [Main - Client Connections](../client-user-interface/server/main-client-connections).

To switch to another Server, select it in the server combo box at the left end of the toolbar. See [Server Selection](../client-user-interface/toolbar/server-selection).
