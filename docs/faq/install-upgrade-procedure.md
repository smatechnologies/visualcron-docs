## How Do I Install VisualCron / Upgrade Procedure

This page used to describe how to install VisualCron and how to upgrade an existing installation. For the current steps, see [Download, Install, Upgrade, and Uninstall](../get-visualcron/download-install-upgrade-uninstall).

Upgrade at a time when no Jobs are running, because the setup program stops the VisualCron service during the upgrade.
