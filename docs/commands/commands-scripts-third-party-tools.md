## Commands, Scripts, and Third Party Tools

Besides its built-in Tasks, VisualCron can run any program, Windows command or script, at a set time or when a Trigger fires. This section is for anyone who wants to automate work that has no dedicated Task, with the commands that ship with Windows, a scripting language, or a program from another vendor. Most of this work runs through the [Execute Task](../client-user-interface/server/job-tasks-task-process-execute).

To suggest a command, program or utility that works well with VisualCron, use the [contact page](https://www.visualcron.com/contact.aspx).

This section has three parts:

- [Commands and Batch Files](commands-and-batch-files): run Windows commands and batch files
- [Scripts](scripts): choose a Task for each kind of script, and run PHP and VBScript scripts
- [Third-party tools](scripts#third-party-tools): run programs from other vendors, such as NirCmd

For new scripts, consider the [PowerShell Task](../client-user-interface/server/job-tasks-task-process-powershell). Microsoft has deprecated VBScript.
