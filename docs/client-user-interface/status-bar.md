## Overview

The status bar is at the bottom of the Client window. From left to right it shows:

- ***Events***: opens the list of [Client events](client-events)
- _Server_: the address of the connected Server; see [Server name](server-name)
- _Server time_: the current time on the connected Server; see [Server time](server-time)
- _Jobs_: the number of Jobs on the connected Server that you can see
- _Startup metrics_: how many seconds the Client took to load and to show the main window

A progress bar on the right shows the progress while the Client connects to a Server.
