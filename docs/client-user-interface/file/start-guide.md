## Settings - Start Guide

The ***File*** -> ***Settings*** -> ***Start guide*** option opens the ***Get started*** guide that is shown when VisualCron is installed for the first time. Click ***Next*** and ***Previous*** to move through the pages, and ***Finish*** to close it.

![The first page of the Get started guide, opened from the Start guide button on the File tab](../../../static/img/Client%20User%20Interface/Main%20Menu/File/Start%20Guide.png)

The second page shows whether VisualCron is set up as "Client and Server" or "Client only", and the state of the Server service and the Tray Client.

![The Get started page with the Client and Server and Client only options and the service and Tray Client status](../../../static/img/Client%20User%20Interface/Main%20Menu/File/Start%20Guide%202.png)

The last page lists where to get help: the help file, the VisualCron forum, the video tutorials and e-mail support.

![The Get started page that lists the help file, forum, video tutorials and e-mail contact](../../../static/img/Client%20User%20Interface/Main%20Menu/File/Start%20Guide%203.png)
