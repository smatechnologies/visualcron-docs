## Translation - Open Translation Page

The ***File*** -> ***Translation*** -> ***Open translation page*** option opens the [VisualCron translation page](https://www.visualcron.com/translation/translationstart.aspx) in your web browser. Use it to contribute translations, for example if your language is missing or a caption is not yet translated.

For help getting started, contact [VisualCron support](https://www.visualcron.com/contact.aspx).
