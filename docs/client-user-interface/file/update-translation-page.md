## Translation - Update Translation Files

The ***File*** -> ***Translation*** -> ***Update translation files*** option rebuilds the language files for the current Client language. It scans the Client for captions, saves the language files in the `lang` folder of the Client installation and reloads the language, so that new or updated translations take effect.

To contribute translations, see [Translation - Open Translation Page](open-translation-page) or contact [VisualCron support](https://www.visualcron.com/contact.aspx).
