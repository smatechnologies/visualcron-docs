## File

The ***File*** tab of the main menu holds the import and export, update, Client settings, server and translation options. It has these groups:

- ***Import/Export***: [Import settings](import-settings.md), [Export settings](export-settings.md) and [Task scheduler](task-scheduler.md)
- ***Updates***: [Check for updates](check-for-updates.md)
- ***Settings***: [Client settings](client-settings.md), [Start guide](start-guide.md) and ***Video tutorial***, which opens the tutorial wizard
- ***Servers***: [Manage Servers](manage-servers.md)
- ***Translation***: [Open translation page](open-translation-page.md) and [Update translation files](update-translation-page.md)
