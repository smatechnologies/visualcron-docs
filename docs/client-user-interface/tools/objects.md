## Objects

The ***Objects*** group on the ***Tools*** tab opens the windows that show how VisualCron objects are used and changed. Many objects are shared; for example, one Credential can be used by many Tasks and Triggers.

The group has three buttons:

- ***Object relations***: opens the ***Object finder*** window on the ***Object relations*** tab; see [Objects - Object Relations](object-relations)
- ***Object search***: opens the ***Object finder*** window on the ***Object text search/replace*** tab; see [Objects - Object Search](object-search)
- ***Audit log***: see [Objects - Audit Log](objects-audit-log)

The ***Object finder*** window also has the ***Object replace/merge*** tab; see [Objects - Object Replace/Merge](object-replace-merge).
