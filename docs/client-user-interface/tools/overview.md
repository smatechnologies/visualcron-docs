## Overview

The ***Tools*** tab of the main menu groups the windows that help you explore, analyze and maintain your VisualCron setup:

- ***Explore***: [File Explorer](explore-file-explorer), [SQL Explorer](explore-sql-explorer), [Connection Explorer](explore-connection-explorer), [Server monitor](server-monitor) and [Task manager](task-manager)
- ***Objects***: [Object relations](object-relations), [Object search](object-search) and [Audit log](objects-audit-log). [Object replace/merge](object-replace-merge) is a tab in the same window as Object relations
- ***Schedule***: [Calendar](schedule-calendar)
- ***Flow chart***: [Flow chart](flow-chart-flow-chart)
- ***Gantt chart***: [Gantt chart](gantt-chart)

Reports are on the ***Reports*** tab; see [Reports](../reports).
