## Overview

The ***About*** tab of the main menu shows information about VisualCron and lets you suggest a feature.

![The About tab of the main menu, with the About and Feedback groups](../../../static/img/Client%20User%20Interface/Main%20Menu/About/About.png)

- ***About VisualCron***: shows version and license information; see [About VisualCron](about-visualcron)
- ***Suggest a feature***: opens the feature requests section of the VisualCron forum; see [Feedback - Suggest A Feature](feedback-suggest-a-feature)
