## About VisualCron

The ***About*** -> ***About*** -> ***About VisualCron*** option shows version and license information for the Client and the connected Server.

The ***About VisualCron*** window shows:

- _Version_: the Client version
- _Protocol version_: the version of the protocol the Client uses to talk to the Server
- _Build_ and _Build date_: the build of the Client
- _License status_: whether the connected Server is activated or in a trial, with the days left in a trial

The ***Check for updates*** button in the window runs the same check as [Updates - Check for Updates](../file/check-for-updates).
