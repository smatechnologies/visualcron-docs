## Overview

The ***Help*** tab of the main menu opens the documentation and the VisualCron web site. It has these groups:

![The Help tab of the main menu with the Internal and External groups](../../../static/img/Client%20User%20Interface/Main%20Menu/Help/Help.png)

- ***Internal***: [Show documentation](internal-show-documentation) and [API](internal-api)
- ***External***: [Forum](external-forum), [Contact us](external-contact-us) and [Tutorials](external-tutorials)
