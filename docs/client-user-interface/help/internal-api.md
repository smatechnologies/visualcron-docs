## Internal - API

The ***Help*** -> ***Internal*** -> ***API*** option has two choices:

- ***Show documentation***: opens the API documentation, `VisualCronAPI.pdf` in the `API\doc` folder of the Client installation
- ***API reference***: opens the API reference help file, `VisualCronAPI.chm` in the same folder
