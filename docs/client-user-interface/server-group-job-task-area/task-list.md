## Task List

The Task right-click menu in the Server/Group/Job/Task grid holds the actions for the selected Task. Most items work like the Job items in [Job List](job-list/overview), but act on the Task.

The Task items are:

- `Edit Task '<Task name>'`, `Clone Task '<Task name>'` and `Delete Task '<Task name>'`
- ***Delete selected Tasks***, when more than one Task is selected
- `Cut Task '<Task name>'`, `Copy Task '<Task name>'` and ***Paste Task***
- `Run Task '<Task name>'`: see [Run Task](job-list/run-task)
- `Pause Task '<Task name>'` and `Stop Task '<Task name>'`
- `Deactivate Task '<Task name>'` or `Activate Task '<Task name>'`, ***Activate selected Tasks*** and ***Deactivate selected Tasks***
- ***Log history***: see [Task Log](job-list/task-log)
- ***Add to Task repository***

The menu also keeps the Job items for the Job that the Task belongs to, such as `Run Job '<Job name>'` and ***Reset Job***.
