## Overview

The Job right-click menu in the Server/Group/Job/Task grid holds the actions for the selected Job and its Tasks. The toolbar above the grid has ***Add Job***, ***Edit Job***, ***Clone Job***, ***Delete Job*** and ***Run Job***, and ***Pause Job*** while a Job is running.

![Toolbar above the grid with Add Job, Edit Job, Clone Job, Delete Job, Run Job and Grid filter](../../../../static/img/Client%20User%20Interface/Toolbar/Toolbar.png)

![Full Job right-click menu in the Server/Group/Job/Task grid](../../../../static/img/Client%20User%20Interface/Toolbar/Right%20Click%20Options.png)

The menu has these items:

- ***Add Job***: see [Add Job](add-job)
- `Add Task to Job '<Job name>'`: see [Add Task to Job](add-task-to-job)
- ***Add to folder***: see [Job folders](../../job-folders)
- `Edit Job '<Job name>'`: see [Edit Job](edit-job)
- `Clone Job '<Job name>'`: see [Clone Job](clone-job)
- `Delete Job '<Job name>'`: see [Delete Job](delete-job)
- ***Delete selected Jobs***: see [Delete Selected Jobs](delete-selected-jobs)
- `Cut Job '<Job name>'`: see [Cut Job](cut-job)
- `Copy Job '<Job name>'`: see [Copy Job](copy-job)
- ***Paste Job***: see [Paste Job](paste-job)
- `Run Job '<Job name>'`: see [Run Job](run-job)
- `Run Job '<Job name>' with options`: see [Run Job With Options](run-job-with-options)
- ***Run selected Jobs***: runs all selected Jobs, ***Without Conditions*** or ***With Conditions***
- ***Triggers***: see [Triggers](triggers)
- ***Run Task***: see [Run Task](run-task)
- `Pause Job '<Job name>'`: pauses a running Job. For a paused Job the item is `Resume Job '<Job name>'`
- `Stop Job '<Job name>'`: see [Stop Job](stop-job)
- `Deactivate Job '<Job name>'` or `Activate Job '<Job name>'`, ***Activate selected Jobs*** and ***Deactivate selected Jobs***: see [Activate/Deactivate Job](activate-deactivate-job)
- ***Reset Job***: see [Reset Job](reset-job)
- ***Log history***: see [Job Log](job-log)
- ***Result***: shows the ***Job result*** or the ***Task result***
- ***Audit log***: see [Audit Log](audit-log)
- ***Versions..***: see [Versions](versions)
- ***Object relations***: see [Object Relations](object-relations)
- ***Show flow chart***: see [Show Flow Chart](show-flow-chart)
- ***Export ...***, ***Send to connection ...*** and ***Send to server connection ...***: export the Job or send it to another Server connection

On a Task row, the menu shows the Task versions of these items; see [Task List](../task-list).
