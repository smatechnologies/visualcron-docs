## Run Task

The `Run Task '<Task name>'` item runs one Task on its own, without the rest of its Job.

1. Right-click the Task in the Server/Group/Job/Task grid.
2. Click `Run Task '<Task name>'`.

The submenu has ***Without raising Trigger Events***, which runs the Task without raising Trigger events. Running a Task requires the Execute permission for the Task and permission to use the Credential that the Task uses.
