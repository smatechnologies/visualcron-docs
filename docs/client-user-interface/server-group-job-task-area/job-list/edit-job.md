## Edit Job

The `Edit Job '<Job name>'` item opens the Job window for an existing Job.

To edit a Job, do one of the following:

- Right-click the Job in the Server/Group/Job/Task grid and click `Edit Job '<Job name>'`
- Select the Job and click ***Edit Job*** on the toolbar

On a Task row, the same item is `Edit Task '<Task name>'` and opens the Task window. For the settings in the Job window, see [Job - Main settings](../../server/job-main-settings).
