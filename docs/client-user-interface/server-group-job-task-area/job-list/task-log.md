## Task Log

The ***Log history*** item on a Task row opens the ***Task history*** window for that Task.

1. Right-click the Task in the Server/Group/Job/Task grid.
2. Click ***Log history***.

The window works like ***Server*** -> ***Information*** -> ***Log*** (see [Information - Log](../../server/information-log)), but shows only the history of the selected Task. Opening it requires the Read permission for the Task.
