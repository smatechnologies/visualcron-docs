## Triggers

The ***Triggers*** item lists the Triggers of the selected Job, so that you can turn one on or off or fire it.

1. Right-click the Job in the Server/Group/Job/Task grid.
2. Point to ***Triggers***.
3. Point to the Trigger. Each Trigger is shown by its description.
4. Click one of these:
   - ***Deactivate*** for an active Trigger, or ***Activate*** for an inactive one
   - ***Fire***: fires the Trigger now. ***Fire*** is available only for an active Trigger
