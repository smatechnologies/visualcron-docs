## Versions

The ***Versions..*** item opens the ***Versions..*** window for the selected Job or Task.

1. Right-click the Job or Task in the Server/Group/Job/Task grid.
2. Click ***Versions..***.

The window is described in [Versions](../../tools/audit-log-versions).
