## Server

The **_Server_** tab of the main menu holds the commands for the Server that the Client is connected to. Use it to switch the Server on or off, change its settings and permissions, check its health and SLA figures, look at failed and running Jobs, and manage the global objects that Jobs and Tasks share.

![The Server tab of the main menu with the groups Main settings, Health, SLA, Jobs, Global objects and Information](../../../static/img/Client%20User%20Interface/Main%20Menu/Updated%20Menu%20Option.png)

The tab has these groups:

- **Main settings**: _Server [On]_ or _Server [Off]_ (see [Main - Server On/Off](server-on-off)), _Settings_ (see [Main - Settings](main-settings)), _User permissions_ (see [Main - User Permissions](main-user-permissions)), _Group permissions_ (groups are described in [Main - User Permissions](main-user-permissions)) and _Client connections_ (see [Main - Client Connections](main-client-connections))
- **Health**: the current health status of the Server; click it to open the Server health window (see [Health - Server Health](health-server-health))
- **SLA**: _Uptime_, _Outages_ and _Latency_ (see [SLA - Uptime, Outages, Latency](sla-uptime-outages-latency))
- **Jobs**: _Failed Jobs_ (see [Jobs - Failed Jobs](jobs-failed-jobs)), _Running Jobs_ (see [Jobs - Running Jobs](jobs-running-jobs)) and _ROI_ (see [ROI - Return On Investment](roi-return-on-investment))
- **Global objects**: [Certificates](global-certificates), [Conditions](global-conditions), [Connections](global-connections), [Credentials](global-credentials), [Network drives](global-network-drives), [Notifications](global-notifications), [PGP Key Rings](global-pgp-key-rings), [Time exceptions](global-time-exceptions), [Variables](global-variables), [Task repository](global-task-repository) and [SSH keys](global-ssh-keys)
- **Information**: _Log_ (see [Information - Log](information-log)), _Server info_ (see [Information - Server Info](information-server-info)) and _License_ (see [Information - License](information-license))
