## Task - Task Type

Based on the selected Task type in the Task > Main settings tab, this tab reflects the current Task type selection and provides additional specific Task type settings. Each Task type's settings are on its own page, listed under [Task - Main Settings](job-tasks-task-main-settings) in the table of contents.
