## Overview

The Portable Document Format (PDF) is a file format used to present documents in a manner independent of application software, hardware, and operating systems.

The PDF Tasks in VisualCron read, change, sign, encrypt and convert PDF files. Most PDF Tasks select their source files on a ***File filter*** tab. The Tasks that save files have a _Save to.._ group, usually on a ***Destination*** tab, whose _Same file_ option, in most of them, replaces the source file. Get field(s), Get information and Search text write their results to the Task output instead.

The ***Main settings***, ***Flow***, ***On error***, ***Conditions*** and ***TimeOut*** tabs are the same for every Task; see [Job - Tasks](../../job-tasks).
