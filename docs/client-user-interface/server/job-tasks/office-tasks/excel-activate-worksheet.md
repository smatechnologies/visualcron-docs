## Task Office - Excel - Activate Worksheet

The Excel - Activate worksheet Task sets which worksheet is active (selected) when the Excel file is opened, and saves the file afterwards.

![](../../../../../static/img/Client%20User%20Interface/Main%20Menu/Server/Jobs/Job%20Tasks/Tasks/Office%20Tasks/Excel%20Activate%20Worksheet.png)

**Credentials**

To control a remote computer you may need to use a Credential. The Credential must match the user name and password of the user that you want to login for. Select a Credential in the combo box or click the *Settings* icon to open *Manage credentials* in order to add or edit Credentials.

**Select Excel file**

Select the full path to the Excel file.

**Password**

Enter the password for the Excel file, if it is password protected.

**Worksheet**

**By name** / **By index**

Select **By name** to choose the worksheet by its name. Click the **Get** button to populate the list with worksheets from the selected file. The Task fails if no worksheet with this name exists.

Select **By index** to choose the worksheet by its position in the workbook. The index starts at 0, so the first worksheet is 0, the second is 1, and so on.
