## Task Office - Excel - Rename Worksheet

The Excel - Rename worksheet Task renames an existing worksheet in an Excel file and saves the file afterwards.

![](../../../../../static/img/Client%20User%20Interface/Main%20Menu/Server/Jobs/Job%20Tasks/Tasks/Office%20Tasks/Excel%20Rename%20Worksheet.png)

**Credentials**

To control a remote computer you may need to use a Credential. The Credential must match the user name and password of the user that you want to login for. Select a Credential in the combo box or click the *Settings* icon to open *Manage credentials* in order to add or edit Credentials.

**Select Excel file**

Select the full path to the Excel file.

**Password**

Enter the password for the Excel file, if it is password protected.

**Worksheet**

**Old worksheet name**

Select the worksheet to rename. Click the **Get** button to populate the list with worksheets from the selected file. The Task fails if no worksheet with this name exists.

**New worksheet name**

Enter the new name for the worksheet.
