## Overview

Microsoft Message Queuing (MSMQ) is a message queue implementation developed by Microsoft and shipped with Windows Server and Windows client operating systems.

The MSMQ Tasks work with queues on the Server computer or on a remote computer. Both Tasks have the same **Scope** settings (_Local MSMQ_ or _Remote MSMQ_, _Credential_ and _Host name_) and the same **Queue** setting.

**Available MSMQ Tasks**

* [MSMQ - Send message](send-message)
* [MSMQ - Delete message(s)](delete-message)
