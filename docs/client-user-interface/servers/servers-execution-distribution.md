## Servers - Execution Distribution

The ***Execution distribution*** group on the ***Servers*** tab of the ribbon opens the [Load Balancer](load-balancer) windows.

![Execution distribution group with the Load balancer, Flows, Agents and Logs buttons](../../../static/img/Client%20User%20Interface/Main%20Menu/Servers/Execution%20Distribution/Execution%20Distribution.png)

- _Load balancer_: opens the ***Load balancer*** window, with the [Broker Server](broker-server) and Server Agent settings, the [distributed execution](execution-distribution) settings, and the ***Agents***, ***Flows*** and ***Logs*** tabs
- _Flows_: opens the ***Load balancing flows*** window, where [Load balancing Flows](load-balancing-flows) are configured and their runtime status is shown
- _Agents_: opens the ***Server Agents*** window, which lists the Server Agents connected to the Broker and turns their Scheduler role on or off. See [Scheduler monitoring and controlling](broker-server#scheduler-monitoring-and-controlling)
- _Logs_: opens the Client events window, filtered to load balancing events

The buttons are unavailable when the license does not include Load Balancing; see [Load Balancer](load-balancer).
