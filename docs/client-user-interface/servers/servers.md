## Servers

The ***Servers*** tab of the ribbon groups the windows for syncing, failover, the MFT Server and Load Balancing.

![Servers tab of the ribbon with the Sync settings, Failover, MFT, Cloud and Execution distribution groups](../../../static/img/Client%20User%20Interface/Main%20Menu/Servers/Servers.png)

- _Sync Server objects_ (***Sync settings*** group): copies Jobs and global objects from another VisualCron Server. See [Sync Server Objects](sync-server-objects)
- _Windows Failover Cluster_ (***Failover*** group): settings for running VisualCron in a Windows Failover Cluster. See [Using VisualCron in a clustered environment](../../using-visualcron/using-visualcron-in-a-clustered-environment)
- _Managed File Transfer_ (***MFT*** group): hosts SFTP and FTP servers inside VisualCron. See [MFT Server](servers-mft)
- _Load balancer_, _Flows_, _Agents_ and _Logs_ (***Execution distribution*** group): configure and monitor Load Balancing. See [Servers - Execution Distribution](servers-execution-distribution)
