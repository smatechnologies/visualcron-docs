## Overview

The ***Interface*** tab of the main menu controls how the main grid lists Servers, Jobs and Tasks, and the Client theme.

![The Interface tab of the main menu with the Columns, Filter and Theme groups](../../../static/img/Client%20User%20Interface/Main%20Menu/Interface/Interface.png)

It has these groups:

- ***Columns***: [Group Jobs](columns-group-jobs), [Set columns](columns-set-columns) and [Expand all](columns-expand-all)
- ***Filter***: [Grid filter](filter-grid-filter) and [Clear filter](filter-clear-filter)
- ***Theme***: a combo box to switch the Client theme between "Dark blue", "Dark grey" and "Light grey"
