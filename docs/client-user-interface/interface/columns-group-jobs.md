## Columns - Group Jobs

The ***Interface*** -> ***Columns*** -> ***Group Jobs*** option groups the Jobs in the main grid by their Job group. The setting is kept for the next time the Client starts.

When it is selected, the Jobs are shown under a row for each Job group:

![The main grid with Group Jobs selected, showing the Jobs under their Job group rows](../../../static/img/Client%20User%20Interface/Main%20Menu/Interface/Group%20Jobs%20selected.png)

When it is cleared, all Jobs are shown in one list:

![The main grid with Group Jobs cleared, showing all Jobs in one list](../../../static/img/Client%20User%20Interface/Main%20Menu/Interface/Group%20Jobs%20not%20selected.png)
