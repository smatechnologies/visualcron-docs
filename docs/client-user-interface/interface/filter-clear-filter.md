## Filter - Clear Filter

The ***Interface*** -> ***Filter*** -> ***Clear filter*** option clears all fields of the grid filter, so that the main grid shows all rows again. The ***Clear*** button in the grid filter does the same. See [Filter - Grid Filter](filter-grid-filter).
