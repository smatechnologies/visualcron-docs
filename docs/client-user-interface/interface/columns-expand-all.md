## Columns - Expand All

The ***Interface*** -> ***Columns*** -> ***Expand all*** option expands every row in the main grid, so that all Jobs and Tasks of each Server are shown.

![The Expand all button on the Interface tab, with the Server row collapsed in the main grid](../../../static/img/Client%20User%20Interface/Main%20Menu/Interface/Expand%20All.png)

After you expand, the button reads ***Collapse all***. Click it to collapse all rows again.

![The main grid with all Job groups, Jobs and Tasks expanded and the Collapse all button](../../../static/img/Client%20User%20Interface/Main%20Menu/Interface/Collapse%20All.png)
