## Edit Job

The ***Edit Job*** button in the toolbar opens the selected Job in the ***Edit Job*** window. If a Task row is selected, the Job that the Task belongs to is opened. See [Edit Job](../server-group-job-task-area/job-list/edit-job) and [Jobs - Jobs](../server/jobs-jobs).
