## Run Job

The ***Run Job*** button in the toolbar runs the selected Job at once. If a Task row is selected, the Job that the Task belongs to runs. You need the execute permission for the Job.

- The Job runs even if it is deactivated
- The Job runs without checking its Job Conditions. To check them, right-click the Job and click `Run Job '<Job name>'` -> ***With Conditions***, which is shown only when the Job has Conditions; see [Run Job](../server-group-job-task-area/job-list/run-job)

While the Job runs, the button reads ***Stop Job***, and clicking it stops the Job. A ***Pause Job*** button is also shown; while the Job is paused, it reads ***Resume Job***.
