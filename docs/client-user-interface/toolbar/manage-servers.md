## Manage Servers

The ***Manage Servers*** button in the toolbar, next to the Server selection combo box, opens the ***Manage servers*** window, the same as ***File*** -> ***Servers*** -> ***Manage Servers***. See [Servers - Manage Servers](../file/manage-servers).
