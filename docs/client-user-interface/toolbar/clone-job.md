## Clone Job

The ***Clone Job*** button in the toolbar opens a copy of the selected Job in the ***Clone Job*** window. The copy gets new Ids and its run statistics are reset. It is created when you click ***Ok***. See [Clone Job](../server-group-job-task-area/job-list/clone-job) and [Jobs - Jobs](../server/jobs-jobs).
