## Errors When Trying to Open an External Link from VisualCron

This page is about an earlier version of VisualCron. It does not apply to current versions. It described a bug in Firefox 2.

The Client opens links through Windows, which passes them to your default browser. If a link does not open and the Client shows "There was a problem opening the link", set a default browser in Windows *Settings* -> *Apps* -> *Default apps* (on older Windows Server versions, *Control Panel* -> *Default Programs*), then try the link again.
