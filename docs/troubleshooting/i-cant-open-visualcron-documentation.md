## I Cannot Open VisualCron Documentation

This page is about an earlier version of VisualCron. It does not apply to current versions. The VisualCron documentation is not a PDF file, so Adobe Reader is not needed: *Show documentation* on the ***Help*** tab of the Client opens the help file installed with VisualCron, and the same help is online at [help.visualcron.com](https://help.visualcron.com).
