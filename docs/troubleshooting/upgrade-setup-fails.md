## Upgrade/Setup Fails

This page is about an earlier version of VisualCron. It does not apply to current versions. The current setup program removes the installed version itself and keeps your settings, so the repair with the Windows Installer CleanUp Utility that this page described is not needed.

If an upgrade fails, see [Installation troubleshooting](../get-visualcron/download-install-upgrade-uninstall#installation-troubleshooting).
