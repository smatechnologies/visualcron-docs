## Errors on Windows 98/ME

This page is about an earlier version of VisualCron. It does not apply to current versions. VisualCron requires .NET Framework 4.8, which does not run on Windows 98 or Windows ME.

For the supported versions of Windows, see [Requirements](../requirements).
